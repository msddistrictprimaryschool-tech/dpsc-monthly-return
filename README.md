# মুর্শিদাবাদ জেলা প্রাথমিক বিদ্যালয় সংসদ — মাসিক বিবরণী ওয়েব অ্যাপ (DPSC Monthly Return Web App)

এই ফোল্ডারে আপনার পাবলিক ওয়েব অ্যাপের (GitHub Pages) জন্য প্রয়োজনীয় ফাইলগুলো রয়েছে:

1. **`index.html`** — মূল ওয়েব অ্যাপ্লিকেশন (আধুনিক স্মার্ট ফর্ম + সরকারি A4 প্রিন্ট ফরম্যাট, ক্যালেন্ডার ডেট পিকার এবং মাস্টার ডেটা সেভ সুবিধা সহ)।
2. **`styles.css`** — আধুনিক ও স্লিক ডিজাইনের এক্সটার্নাল স্টাইলশিট (Modern Sleek CSS Variables, Card UI, Responsive Inputs, এবং `@media print` A4 Landscape প্রিন্ট স্টাইল)।

## GitHub Pages-এ আপডেট করার নিয়ম:
1. আপনার GitHub Repository-তে যান।
2. **Add file** → **Upload files**-এ ক্লিক করুন।
3. এই ZIP ফাইল থেকে **`index.html`** এবং **`styles.css`** ফাইল দুটি একসাথে টেনে (Drag & Drop) আপলোড করুন।
4. নিচে **Commit changes** বাটনে ক্লিক করুন। ১–২ মিনিটের মধ্যে আপনার লাইভ লিঙ্কে নতুন আধুনিক ডিজাইন ও `styles.css` চালু হয়ে যাবে।
